部署我的私人站点

1. 保存站主认领口令

口令在此设备生成。部署时填入 Cloudflare 的 CLAIM_SECRET，首次打开站点时再用它认领。

2. 部署到你的 Cloudflare

在 Cloudflare 连接你的 GitHub 或 GitLab，确认 Worker、D1、私有 R2 和队列名称。首次使用 R2 时，Cloudflare 可能要求你开通 R2。资源和账单归当前选择的账号。

3. 认领并连接设备

打开部署成功页给出的 workers.dev 地址，创建本站账号。电脑登录后可生成手机配对码，APK 也可以填写站点地址并用同一个账号登录。
